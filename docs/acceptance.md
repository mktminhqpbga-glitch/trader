# AC-01 — Nhật ký nghiệm thu

| Kiểm tra | Trạng thái hiện tại | Bằng chứng |
|---|---|---|
| GitHub chứa mã nguồn Web/Server mới | Đã ghi mã nguồn | Commit nhánh feat/aiCanvasStudioFoundation |
| Bun install | NOT TESTED | Chưa có Bun trong môi trường thực hiện |
| Typecheck | NOT TESTED | Chưa cài phụ thuộc |
| Build | NOT TESTED | Chưa cài phụ thuộc |
| Mở Web thật | NOT TESTED | Chưa chạy localhost |
| API GET /api/health trả 200 và SQLite SELECT 1 | NOT TESTED | Chỉ xác minh tĩnh bằng mã nguồn |
| Backend tắt → UI báo lỗi → bật lại và retry | NOT TESTED | Chưa thử trên trình duyệt |
| DB sai đường dẫn trả 503 | NOT TESTED | Chưa thực thi |
| Restart bảo toàn DB | NOT TESTED | Chưa thực thi |
| MapID hiển thị thực tế | NOT TESTED | Chưa kiểm tra DOM |

**Cấm báo AC-01 DONE** cho đến khi toàn bộ tiêu chí thích hợp được kiểm chứng. Không có chứng cứ kiểm thử không phải PASS.
